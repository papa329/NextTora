Le Problème Historique

Depuis plusieurs siècles, le problème d'échange de codes secrets a toujours été considéré comme une difficulté majeure en cryptographie. Les ambassades et les États-majors ont fait d'importants efforts dans ce sens, tandis que les pirates cherchaient constamment à dévier ces échanges.

Avec l'utilisation des ordinateurs, de la télétransmission et de la dématérialisation de l'information, le problème apparaît sous un angle différent. Dans les années 1970, un chercheur indépendant, Whitfield Diffie, réfléchissait aux moyens par lesquels deux utilisateurs du réseau ARPANET pouvaient échanger des messages électroniques chiffrés sans jamais se rencontrer physiquement pour choisir un code secret commun.

1970

La Réflexion Initiale

Whitfield Diffie commence à réfléchir au problème d'échange de clés sur ARPANET, l'ancêtre d'Internet.

1974

La Conférence Décisive

Diffie présente une conférence au centre de recherche Thomas J. Watson d'IBM à Yorktown Heights, où il découvre que Martin Hellman de l'université Stanford travaille sur le même problème.

Fondements Mathématiques

Arithmétique Modulaire : La Base

La solution de Diffie et Hellman repose sur un chapitre de l'arithmétique que les informaticiens utilisent abondamment : l'arithmétique modulaire, une arithmétique basée sur les classes d'équivalence modulo n.

Division Euclidienne :

a ÷ b → a = b × k + r

Où k est le quotient et r le reste de la division.

13 ÷ 3 → 13 = 3 × 4 + 1

Classes d'Équivalence Modulo 3 :

4 ≡ 1 mod 3 (car 4 = 3 × 1 + 1)

7 ≡ 1 mod 3 (car 7 = 3 × 2 + 1)

10 ≡ 1 mod 3 (car 10 = 3 × 3 + 1)

⚠️ Condition Importante :

Pour que la multiplication modulaire conserve la structure de groupe, n doit être un nombre premier. Sinon, on obtient des diviseurs de zéro qui détruisent cette structure.

4 × 6 (mod 12) = 24 mod 12 = 0 mod 12

L'Algorithme Diffie-Hellman

Le protocole de l'algorithme Diffie-Hellman utilise la fonction :

K = WX mod P

Où P est un nombre premier et W < P.

1

Paramètres Publics

W = 7 (base)

P = 11 (nombre premier)

2

Secrets Privés

Alex : A = 3

Boris : B = 6

3

Calculs Intermédiaires

α = 7³ mod 11 = 2

β = 7⁶ mod 11 = 4

// Échange Diffie-Hellman simplifié
const W = 7; // Base publique
const P = 11; // Nombre premier public

// Alex choisit un secret privé
const secretAlex = 3;
const publicAlex = modPow(W, secretAlex, P); // = 2

// Boris choisit un secret privé
const secretBoris = 6;
const publicBoris = modPow(W, secretBoris, P); // = 4

// Échange public des valeurs calculées
const sharedSecretAlex = modPow(publicBoris, secretAlex, P); // = 9
const sharedSecretBoris = modPow(publicAlex, secretBoris, P); // = 9

🔑 Le Secret Partagé :

Alex calcule : βA mod P = 4³ mod 11 = 64 mod 11 = 9

Boris calcule : αB mod P = 2⁶ mod 11 = 64 mod 11 = 9

Les deux parties obtiennent le même secret partagé (9) sans jamais l'avoir transmis sur le canal !

Pourquoi C'est Sécurisé ?

Supposons qu'un attaquant, Jean, intercepte les messages publics α = 2 et β = 4. Pour calculer le secret partagé S, il doit résoudre :

7B ≡ 4 mod 11

Pour trouver B, ce qui revient à calculer :

B = log7 4 mod 11

💡 Le Problème du Logarithme Discret :

Dans le monde des nombres réels, la solution serait simple : B = log(4)/log(7). Mais dans le monde des classes d'équivalence modulo n, ce problème n'a pas de solution simple connue.

C'est ce qu'on appelle le problème du logarithme discret, sur lequel repose la sécurité de l'algorithme Diffie-Hellman.

🎯

Facile dans un sens

Calculer 7⁶ mod 11 = 4 est rapide et facile pour un ordinateur.

🚫

Difficile dans l'autre

Trouver l'exposant B tel que 7ᴮ ≡ 4 mod 11 est extrêmement difficile pour de grandes valeurs de P.

L'Héritage : Cryptographie à Clé Publique

L'inspiration de Diffie-Hellman a conduit à une découverte encore plus importante : la cryptographie à clé publique, où une paire de clés (publique/privée) permet à quiconque de chiffrer un message, mais seule la clé privée correspondante peut le déchiffrer.

Message chiffré = f(clé publique, message clair)

Message clair = g(clé privée, message chiffré)

Conclusion

Sans aucun doute, l'algorithme Diffie-Hellman représente une découverte majeure en cryptographie. Il offre aux acteurs des cryptosystèmes la possibilité d'échanger un code secret sans que celui-ci ne doive circuler sur tout le réseau.

Mais une autre découverte, encore plus importante, s'inspire de ce principe : un cryptosystème basé sur une paire de clés où l'une sert au chiffrement (clé publique) et l'autre au déchiffrement (clé privée), la clé publique étant publiée dans un annuaire accessible à tous !
